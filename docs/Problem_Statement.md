# Problem Statement

## 1. Title
Gaming Event Ticket and Registration Platform

## 2. Domain
Gaming Event Management

## 3. Users
- User
- Organizer
- Admin

## 4. Problem
Managing gaming events manually is difficult. Users need an easy way
to find events and book tickets. Organizers need a simple system to
manage events and registrations.

## 5. Proposed Solution
We will develop a platform where users can view gaming events,
register for events, and book tickets. Organizers can create and
manage events, while admins can manage the entire system.

## 6. Database Tables
- User
- Event
- Ticket
- Registration
- Payment

## 7. User Roles
- Admin
- Organizer
- User

## 8. Success Criteria
Users can successfully register, view events, and book tickets.

## 9. Out of Scope
- Online gaming
- Real-money betting
- Live streaming

## 10. Chosen Track
Python - FastAPI
